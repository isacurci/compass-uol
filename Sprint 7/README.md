# Resumo

Nesta sprint, avancei no desenvolvimento de habilidades em **Data Warehousing** e **automação de processos de dados**, focando na criação de jobs ETL e implementação de crawlers para captura automatizar todo processo. O objetivo foi consolidar conhecimentos em modelagem dimensional, operações OLAP e desenvolvimento de pipelines  de dados, complementando o desafio iniciado nas sprints anteriores.

---

## 🎓 Cursos Realizados

### **Modelagem de Dados para Data Warehouse**

- Fundamentos teóricos sobre Data Warehousing, seus objetivos principais e fatores críticos para implementação bem-sucedida.
- Compreensão das diferenças fundamentais entre sistemas transacionais (OLTP) e analíticos (OLAP), incluindo aspectos de performance e casos de uso.
- Técnicas avançadas de análise multidimensional para exploração eficiente de dados em cubos OLAP.
- Metodologias e melhores práticas para construção de Data Warehouses, desde o design até a implementação.
- Conceitos fundamentais sobre tabelas de dimensão, tipos de dimensões e sua importância na modelagem dimensional.
- Aprofundamento em técnicas avançadas de modelagem dimensional, incluindo dimensões que mudam lentamente (SCD).
- Características e design de tabelas fato, métricas, granularidade e relacionamentos com dimensões.
- Implementação prática do modelo Star Schema para análises multidimensionais eficientes.

### *Amazon Q Developer*

- Utilização da ferramenta de IA da Amazon para desenvolvimento assistido, otimização de código e automação de tarefas de desenvolvimento.
