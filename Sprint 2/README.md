# Resumo

**Python:** Durante esta sprint, aprimorei meus conhecimentos em Python, abordando diversos conceitos fundamentais. Comecei a trabalhar com listas e funções de alta ordem, como map(), filter(), reduce() e lambda, que me ajudaram a realizar manipulações eficientes de dados e transformações de listas. Aprofundei também no uso de strings, dicionários, arquivos JSON e CSV, e como trabalhar com esses formatos de dados de maneira eficaz. A programação orientada a objetos (OOP) também foi explorada, onde estudei conceitos como classes, herança, polimorfismo e encapsulamento. Esses aprendizados me deram uma base sólida para estruturar programas de forma modular e reutilizável, utilizando conceitos importantes como atributos, métodos e instâncias.

**Manipulação de Arquivos e Dados:** Aprendi a trabalhar com diferentes tipos de arquivos, como arquivos de texto e CSV, realizando a leitura e processamento dos dados para gerar relatórios e realizar cálculos. Utilizei o método open() para manipulação de arquivos e o json.load() para trabalhar com arquivos JSON. Também explorei como manipular dados em arquivos CSV, parseando o conteúdo com funções próprias e processando as informações de maneira prática.

**Programação Orientada a Objetos (OOP):** Esta sprint me proporcionou um bom entendimento sobre classes e objetos. Criei classes com atributos e métodos, trabalhei com herança e sobrescrita de métodos, o que me permitiu aplicar conceitos de OOP de maneira eficiente em diferentes problemas. Exemplos como a criação da classe Lampada, Aviao, e Calculo me ajudaram a consolidar esses conceitos e a utilizá-los para organizar o código de forma mais estruturada e reutilizável.

**Funções de Alta Ordem e Lambda:** Durante os exercícios, apliquei as funções de alta ordem para transformar e processar dados. A utilização de funções lambda foi especialmente útil para operações rápidas de filtragem e transformação de listas, tornando o código mais conciso e eficiente.
