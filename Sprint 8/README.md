# Resumo

Nesta sprint, avancei no desenvolvimento de habilidades em **Business Intelligence (BI)** com foco no **Amazon QuickSight**, aprofundando conhecimentos desde a introdução à ferramenta até técnicas mais avançadas de análise e visualização de dados.  
O objetivo foi consolidar práticas desde o início do programa de bolsas, praticando a criação de dashboards interativos, revendo a modelagem de relacionamentos e por fim, resolvendo o desafio final.

---

## 🎓 Cursos Realizados

### **AWS Getting Started QuickSight**
- Fundamentos do QuickSight e visão geral da ferramenta.  
- Criação de análises e dashboards interativos na nuvem AWS.  
- Conexão com diferentes fontes de dados, incluindo S3 e Athena.  
- Configuração básica para consumo de dados e preparação de relatórios.  

### **Complete Introduction to Amazon QuickSight (Udemy)**
- Aprendizado passo a passo em vídeo HD, com abordagem prática.  
- Método rápido para dominar o AWS QuickSight e criar análises de forma eficiente.  
- Criação de análises, relatórios e insights a partir de dados.  
- Cálculos de tabela: porcentagens, totais acumulados, classificação e diferenças.  
- Exploração de diferentes tipos de visualizações para entender os dados.  
- Carregamento e preparação de dados para análise.  
- Criação de relacionamentos entre dados para análises aprimoradas.  
- Curso voltado para usuários da AWS e também profissionais acostumados com ferramentas da Microsoft e Google.  

---

## 🚀 O que foi desenvolvido

### 1. **Fundamentos de BI com QuickSight**
- Entendimento da estrutura e funcionalidades do Amazon QuickSight.  
- Criação de análises iniciais utilizando dados já disponíveis no Data Lake.  

### 2. **Visualizações Interativas**
- Construção de diferentes gráficos (barras, linhas, dispersão, KPIs e dashboards completos).  
- Aplicação de boas práticas de visualização de dados para transmitir insights de forma clara.  

### 3. **Cálculos e Relacionamentos**
- Implementação de cálculos personalizados para enriquecer análises.  
- Utilização de relacionamentos entre tabelas para análises multidimensionais.  

---

## 👩‍💻 Conclusão

Esta sprint foi essencial para fortalecer minhas habilidades em **Business Intelligence na AWS**, especialmente com o **QuickSight**.  
O aprendizado tanto do curso introdutório quanto do curso completo da Udemy me deu segurança para construir análises mais robustas e visuais interativos, trazendo valor estratégico ao uso dos dados processados no Data Lake.
